Pipeline de dados de mercado financeiro — produção no Snowflake
Production-grade financial market data pipeline on Snowflake
↗ GitHub

Pipeline completo de dados do mercado de ações americano (14 tickers, ~21 mil linhas/ticker, 2020–2025) construído inteiramente dentro do Snowflake. Demonstra padrões de engenharia de dados de produção: ingestão em lote via COPY INTO, CDC com Streams, orquestração automática com Task DAG, indicadores técnicos com window functions e Python/Snowpark rodando dentro da plataforma.

End-to-end US equity market pipeline (14 tickers, ~21k rows/ticker, 2020–2025) built entirely inside Snowflake. Demonstrates production Data Engineering patterns: batch ingestion via COPY INTO, CDC with Streams, automated Task DAG orchestration, technical indicators via window functions, and Python/Snowpark running inside the platform.
